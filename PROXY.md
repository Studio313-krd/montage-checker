# Определение Proxy

ProxyDetector — отдельный модуль Windows Agent. Proxy считается продуктивной машинной работой независимо от `HumanState`: заблокированный или idle-компьютер может продолжать создавать proxy-файлы.

## Условия определения

Начальные правила содержат Adobe Media Encoder, DaVinci Resolve и FFmpeg. Администратор может добавить другой encoder. Для кандидата обязательны одновременно:

- процесс из активного Proxy-правила;
- созданный или растущий видеофайл в активной Proxy-папке компьютера.

CPU и process I/O повышают confidence и помогают связать рост файла с encoder. Filename patterns (`*_Proxy.mov`, `*_Proxy.mp4`, `*proxy*.mxf`) также повышают confidence, но неизменный файл с подходящим именем не запускает Proxy.

## Confidence

| Сигнал | Баллы |
| --- | ---: |
| Известный encoder | 20 |
| CPU выше порога | 25 |
| Process I/O write выше порога | 20 |
| Proxy-файл создан или растёт | 25 |
| Файл найден в Proxy-папке | 20 |
| Известное видео-расширение | 5 |
| Имя совпало с правилом | 15 |

Оценка ограничивается 100. Начальный минимум — 70. Даже CPU + I/O известного encoder без растущего Proxy-файла дают только 65 и не меняют состояние.

Кандидат должен непрерывно наблюдаться 15 секунд. После подтверждения короткие паузы удерживаются 30 секунд; исчезновение encoder завершает Proxy сразу. Оба интервала редактируются в правиле.

## Приоритет Render

Render- и Proxy-папки доставляются Agent раздельно. Если encoder пишет в Render Folder, выбирается `RENDER`; если он пишет в Proxy Folder, выбирается `PROXY`. При случайном пересечении настроек явный растущий файл Render имеет приоритет. Подтверждённый Proxy, в свою очередь, имеет приоритет над Render, полученным только по CPU/I/O без файла.

## Admin API

Endpoints доступны OWNER и ADMIN:

- `GET/POST /api/admin/proxy-rules`;
- `PUT /api/admin/proxy-rules/{ruleId}`;
- `GET/POST /api/admin/computers/{computerId}/proxy-folders`;
- `PUT/DELETE /api/admin/computers/{computerId}/proxy-folders/{folderId}`.

Изменения аудируются и поступают в `GET /api/agent/config`. Поля, ошибки и эксплуатационные сообщения русскоязычные; отдельный экран управления появится на этапе полного Web UI.
