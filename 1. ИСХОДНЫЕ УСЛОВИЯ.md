Ты — senior software architect, senior C#/.NET developer, backend developer, frontend developer и DevOps engineer.

Нужно с нуля разработать полноценную self-hosted систему учёта работы небольшого монтажного отдела.

Система предназначена для компании и устанавливается на рабочие компьютеры сотрудников с их уведомлением. Не делать скрытый кейлоггер, перехват паролей, переписки или другую скрытую слежку. # 10. RENDER STATE MACHINE

Нельзя использовать правило:

Media Encoder открыт = Render.

Сделать scoring/state machine.

Например:

RenderCandidate получает признаки:

knownRenderProcessRunning
processCpuAboveThreshold
processDiskWriteAboveThreshold
gpuActivity
outputFileCreated
outputFileGrowing
knownRenderFolder
knownVideoExtension

RENDER_START только если несколько признаков сохраняются определённое время.

Например:

RenderConfirmSeconds = 15.

Пример сильного сигнала:

Adobe Media Encoder работает
+
output.mp4 увеличивается
+
есть CPU/Disk activity

= RENDER.

Другой пример:

aerender.exe работает
+
CPU высокий
+
идёт запись файлов

= RENDER.

RENDER_END:

процесс завершился;

ИЛИ

файл перестал расти и CPU/IO упали ниже порога в течение, например, 30 секунд.

Все thresholds должны задаваться конфигурацией.

Защититься от постоянного переключения состояний туда-сюда.

Использовать debounce/hysteresis.
